# Template Images

This directory contains thumbnail and preview images for the template inventory.

## Required Images

The following images are referenced in `src/data/inventory.ts` and need to be added:

### Modern SaaS Hero

- `modern-saas-thumb.webp` - Thumbnail (recommended: 400x300)
- `modern-saas-preview.webp` - Full preview (recommended: 1200x800)

### Dark DevTool Landing

- `dark-devtool-thumb.webp` - Thumbnail (recommended: 400x300)
- `dark-devtool-preview.webp` - Full preview (recommended: 1200x800)

### Playful B2C Startup

- `playful-b2c-thumb.webp` - Thumbnail (recommended: 400x300)
- `playful-b2c-preview.webp` - Full preview (recommended: 1200x800)

### Enterprise Security Platform

- `enterprise-security-thumb.webp` - Thumbnail (recommended: 400x300)
- `enterprise-security-preview.webp` - Full preview (recommended: 1200x800)

### Minimal Newsletter Signup

- `minimal-newsletter-thumb.webp` - Thumbnail (recommended: 400x300)
- `minimal-newsletter-preview.webp` - Full preview (recommended: 1200x800)

## Image Guidelines

- Use `.webp` format for optimal performance
- Thumbnails: 400x300px recommended for gallery grid
- Previews: 1200x800px recommended for detail modal
- Optimize images for web (target < 100KB for thumbnails, < 500KB for previews)
