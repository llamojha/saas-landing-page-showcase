A curated gallery of beautiful SaaS landing page templates with AI-ready prompts. Browse visually, copy the prompt, and generate your own landing page using AI tools like v0.dev or bolt.new.

Created by [No Vibe No Code](https://www.novibenocode.com)

## Features

- 🎨 Visual gallery of curated landing page templates
- 📋 One-click copy prompts for AI code generators
- 🔍 Filter by industry, vibe, and tech stack
- ⚡ Static site with instant load times
- 🌙 Dark mode support

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
